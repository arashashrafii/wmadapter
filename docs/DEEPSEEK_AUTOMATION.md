# DeepSeek Browser Automation

## Goal
Automate DeepSeek Web interaction through a controlled browser session.

## Flow
1. Start Playwright browser.
2. Load persistent profile.
3. Check authentication state.
4. Open DeepSeek chat.
5. Send prompt.
6. Wait for generated response.
7. Extract response text.

## Current Status
The automation layer is prepared. Real selectors must be validated against the current DeepSeek UI during runtime testing.
